# Travel Agent

An AI-based travel planning assistant that creates personalized travel plans based on the user's destination, source, travel dates, budget, and preferences.

## Features

- Creates personalized travel plans
- Accepts source and destination
- Considers travel dates
- Considers user's budget
- Generates an organized itinerary
- Provides day-wise travel planning
- Uses a Flask backend
- Provides API endpoints for travel planning
- Supports booking approval functionality

## Technologies Used

- Python
- Flask
- Flask-CORS
- HTML
- CSS
- JavaScript
- AI-based agent logic
